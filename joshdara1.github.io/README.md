# Joshua Daramola — Portfolio

Static portfolio for https://joshdara1.github.io/, built with HTML, CSS and JavaScript.

## Edit and preview

Update `index.html` for page content, `styles.css` for styling and `app.js` for case studies and interactions. Place images in `assets/`. No build tools or dependencies are needed.

```sh
python3 -m http.server 4173
```

Open http://localhost:4173/. Run `node --check app.js` to check JavaScript syntax.

## Publishing

GitHub Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save. `.nojekyll` preserves the static files. Changes on `main` are then republished automatically.

## Content

Featured: CTRL, BudgetBites Firebase edition, PsychoJS GUI testing and TimetableSystem. Supporting: Python Card Game. Group work is credited in the case study. Confidential university exercises and test data are excluded. The CV is available by email request.
